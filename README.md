使用步骤：
1.下载“.bat”启动文件
2.修改bat文件：“你的llama.cpp启动文件目录”、“你的模型目录”
3.保存.bat文件，双击启动llama

注意事项：只有所需的视觉模型（mmproj）是同一个才能放同一个文件夹，否则必须单独存放。
